## Partial or not implemented

- Live catalogue/enrolment/completion/path mutations and verified NSSTA imports are not complete. The live UI keeps the catalogue synthetic and disables live enrolment rather than fabricating a write.
- The eight-competency survey-analyst reference framework is implemented. The entire requested multi-domain framework, admin editors, version lifecycle and configured live job-role targets are not complete.
- Diagnostic practice is static within an attempt. Fully adaptive question selection and calibrated item response/difficulty models are not implemented.
- Timed/limited/resumable attempts have database enforcement. The timed countdown, full policy editor, protected delayed feedback and cohort-specific assignment UI are not complete.
- Trainer source/answer review, version storage and publication are implemented. Full history browsing, per-question regeneration, complete question-option editing and response-based item analytics are partial.
- Tutor has scoped retrieval, citations, message persistence/clear operation and explicit provider failures. Multiple chat sessions, conversation switching and full personalized-history prompting are not implemented.
- Real role provisioning, organizational user management, framework management, course-priority management, training-plan/cohort assignment and operational audit viewers remain pending. Corresponding pages state limits; they do not contain fake action buttons.
- Document jobs are durable and explicitly processed/retried by their owner. A continuously running unattended processor and scheduled recovery are not deployed. Embedding cost is bounded to 100 chunks per material. Lexical tutor retrieval currently considers at most 100 authorized chunks.
- PDF text extraction is implemented but has not been verified against a broad real PDF corpus. PDF worker native memory, hostile-file scanning and OS isolation need further production hardening. DOCX has document-level, not page-level, locations.
- Video transcription, OCR and arbitrary learner code execution are unavailable. TXT/Markdown transcripts and constrained SQL missions are supported.
- English/Hindi navigation is implemented. Full UI/content translation and expert validation of translated formal questions are not complete.
- Exports are unofficial JSON/CSV/text rather than accredited certificates. Completion does not imply mastery; observed improvement does not prove causation.
- Retention/erasure operations, disaster recovery, load tests, real SSO and independent security/accessibility assessments remain required before real deployment claims.

The definition of done is not satisfied by this checkpoint. No quality percentage, government compliance, production scalability, universal accessibility or absolute security claim is made.
