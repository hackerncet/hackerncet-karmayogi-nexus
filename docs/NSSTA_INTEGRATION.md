# NSSTA and TPAC

NSSTA programme recommendations are a required part of provisional SIH26101 alignment. The demonstration catalogue contains distinct synthetic programme records with eligibility, delivery, duration, competency coverage, source link and an explicitly absent TPAC approval reference. It fabricates no official dates or approvals.

`training_programmes` models real future imports and requires approval-evidence URL for a verified record. No verified programme has been imported. The official documents listing was found, but current minutes and their programme details were not parsed and validated. A source URL alone is not approval evidence.

The administrator NSSTA route opens the dedicated filtered demonstration catalogue. Joint recommendation ranking considers both providers. Verified import tooling, controlled programme publication and enrolment into real programmes remain pending administrative data and implementation.
